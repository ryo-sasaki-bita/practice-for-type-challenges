# practice-for-type-challenges
This is a repository for compiling answers to the “Type Challenge.” Use at your own risk.

## type-challenges
https://github.com/type-challenges/type-challenges 

The goal is to be able to answer all questions up to the **“middle”** level.

## Procedure
1. Create a `feature/<level>-XX-title` branch from the `develop` branch. 
  - You can name the branch whatever you like, but it’s best to use the format above so it’s easy to identify.

2. Create the answer and commit it.

3. Create a pull request to the `develop` branch. Do not merge it.

## Required Items for Each Pull Request
- README.md
  - URL of the problem
  - Your impressions, areas for improvement, and feedback.
- TS file containing the solution
  - You may include your solution or thought process in the comments.
  - If you referenced AI, please specify this.
  - If you referenced another article, please specify this.
